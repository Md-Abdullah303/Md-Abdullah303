### 👨‍💻 Who Am I?

<img align="right" alt="Coding GIF" width="300" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" style="border-radius: 10px;"/>

I am a passionate **Full Stack MERN Developer** based in Chandpur, Bangladesh. I specialize in architecting scalable web applications, bridging the gap between pixel-perfect frontend designs and robust, secure backend systems. With a strong focus on modern JavaScript frameworks like **Next.js** and **React**, I build enterprise-grade software that solves real-world problems.

- 🔭 **Currently Building:** Advanced Full-Stack Systems & Modern SaaS architectures.
- 🌱 **Currently Mastering:** Enterprise-level Next.js (App Router), System Design, and Microservices.
- 💡 **Development Philosophy:** Clean Code, Intuitive UI/UX, and High Performance.
- 💬 **Ask me about:** `React 19`, `Next.js 16`, `Express 5`, `MongoDB`, and `Tailwind CSS v4`.
